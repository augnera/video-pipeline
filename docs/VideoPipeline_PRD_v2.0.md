# VideoPipeline PRD v2.0｜小陈AI说 AI 配音与视频素材匹配生产线

版本：v2.0（需求重定位草案）｜日期：2026-10-27｜状态：待持有人确认、待 Codex 代码审计

## 1. 产品定位

VideoPipeline 接收**已经定稿的 Excel 分镜脚本**，主要解决两个耗时问题：

1. **本人声音克隆与自动配音**：无需每期真人录制整段旁白，支持逐句试听、重生成与替换。
2. **按分镜自动匹配视频画面**：优先复用素材库及标准模板，必要时使用本地 ComfyUI/Wan 生成新场景；真实产品界面只能用真实录屏。

最终自动组装可审核的竖版视频初稿，人工在审核台或剪映中精修并发布。

**明确非目标**：自动选题、自动改写已定稿脚本、自动生成营销文案、数字人对口型、多客户管理、自动发布、初期夜间批量生产。原 dseai.hk 带货工作流保留现状，不在本次 MVP 内扩展。

## 2. 输入与输出

### 2.1 输入：现有 Excel 分镜表

以 Day9《一人公司，3个必须提前做的正确选择》为首个真实样本。当前截图可确认的列包括：

- 分镜画面
- 旁白（口播原文）
- 音效
- 叠加文字规范
- 屏幕裁切建议
- 建议时长
- 统一 BGM 规范
- 视觉规范

实际字段位置、合并单元格、工作表结构与文件版本由 Codex 在拿到真实 XLSX 后检查；**不依赖截图猜测 Excel 结构**。

导入时需展示预览与校验结果；旁白为权威文本，未经确认不得擅自改写。分镜画面与时长是指导性约束，实际时长以最终配音为准。支持部分字段缺失并明确报告。

### 2.2 输出

每次任务生成独立目录，至少包含：

- `script.normalized.json`：Excel 解析结果及原始行映射
- `storyboard.json`：分镜导演决策（画面类型、素材来源、匹配依据、时间线）
- `narration.wav`：完整配音；可选逐句音频
- `subtitles.srt`：基于已知旁白与配音时间对齐的字幕
- `assets/`：实际使用的视频、图片、文字卡、图解与录屏引用清单
- `draft.mp4`：1080×1920、9:16 视频初稿
- `review.json`：待人工检查的镜头、失败和替换记录
- `production.json`：各阶段耗时、模型版本、生成参数、素材来源与重跑状态

输出应能在剪映中通过素材、配音和字幕继续编辑。**不承诺首版生成剪映原生可编辑工程**，该能力单独验证。

## 3. 核心用户流程

1. 用户上传 Day9 XLSX，预览分镜与旁白，确认导入。
2. AI 分镜导演分析每行旁白、分镜画面、叠加文字和时长，生成镜头任务与素材方案。
3. 本地 GPT-SoVITS 以已授权本人音色生成配音；试听后可仅重做不满意的句子。
4. 画面引擎按以下优先级处理：已有合格素材 → 文字卡/图解模板 → 授权素材或真实录屏 → ComfyUI/Wan 新生成。
5. 根据实际配音时间对齐字幕与镜头，FFmpeg 自动合成初稿。
6. 用户检查低置信度或生成失败镜头，替换素材，局部重渲染；最终剪映精修并发布。

## 4. 系统架构

```text
Excel 分镜脚本（已定稿）
        ↓
Excel 导入 / 校验 / 标准化
        ↓
Storyboard Director（AI 分镜导演）
  ├─ 镜头类型判定：情绪场景 / 观点文字卡 / 方法图解 / 真实录屏
  ├─ 素材检索与复用决策
  └─ 时间线与审核点规划
        ↓
  ┌───────────────┬────────────────┬─────────────────┐
  │ GPT-SoVITS    │ 素材库 / 模板  │ ComfyUI + Wan  │
  │ 本人配音      │ 文字卡 / 图解  │ 缺失场景生成    │
  └───────────────┴────────────────┴─────────────────┘
        ↓
字幕对齐 + FFmpeg 自动组装视频初稿
        ↓
人工审核 / 剪映精修 → 手动发布
```

### 4.1 沿用原技术约束

- TypeScript / Node.js 作为编排层，模型通过 HTTP API 访问。
- 保留 GPT-SoVITS、ComfyUI、Whisper（作为校验或备选）、FFmpeg 现有客户端；按审计结果修复。
- GPU 推理任务需要资源互斥与显存预算，避免 Wan 与其他大模型抢占显存。
- 项目数据和模型路径优先放 WSL Linux 文件系统；密钥不进入 Git。
- 每阶段产物落盘，允许失败恢复、单镜头重新生成与局部重新合成。
- 初期不引入数据库或分布式队列。

## 5. 功能需求与验收

### P0｜现有项目与环境审计（必须先做）

**F0.1** 对比本地 main 与 origin/main 的 8 个未推送提交，识别已实现功能和未提交的运行成果。不得覆盖本地代码。

**F0.2** 核查 GPT-SoVITS、ComfyUI、Wan、FFmpeg 的代码、模型文件、工作流和真实可运行证据；本轮只读，不启动推理。

**验收**：功能状态矩阵（已验证/有代码未验证/占位/缺失），列出第一阻断与最短复工路径。

### P1｜Excel 导入 + 分镜导演

**F1.1** 导入真实 Day9 XLSX，保留行号、旁白、画面描述、文字叠加与时长；生成标准 JSON，并报告无法解析的单元格。

**F1.2** Storyboard Director 生成镜头计划，四类画面：A 情绪场景、B 观点文字卡、C 方法图解、D 真实录屏。

**F1.3** 每个镜头必须包含：原始 Excel 行号、旁白、镜头类型、画面描述、素材来源、模板/生成提示词、预计时长、审核原因。

**F1.4** 禁止为了生成画面改写已定稿旁白；无法确定素材时标记人工确认，不能凭空捏造产品 UI。

**验收**：Day9 Excel 可无损导入旁白；输出完整镜头计划；人工可读、可修改；没有未经确认的口播改写。

### P2｜声音克隆与配音

**F2.1** 复用 GPT-SoVITS HTTP 客户端，支持配置本人授权音色的参考音频、参考文本和语言。

**F2.2** 支持逐句生成、试听、局部重生成、合并完整旁白；保存每段与原 Excel 行号的关联。

**F2.3** 根据音频真实长度校正分镜时间；字幕优先使用已知脚本做时间对齐，Whisper 用于异常校验。

**验收**：Day9 全部旁白生成可试听音频，至少一次局部重做不影响其余音频；记录耗时、模型与人工主观质量评分。音色相似度、自然度、停顿和错读需由本人验收。

### P3｜素材匹配与生成

**F3.1** 建立本地素材索引，包含文件路径、语义标签、时长、画幅、来源/授权、复用次数及预览图。

**F3.2** 先用关键词/标签检索；匹配不佳再使用语义检索；设定人工可确认的素材选择结果。

**F3.3** B/C 类优先使用可复用文字卡、图解模板；D 类只使用真实录屏。

**F3.4** A 类在素材库无合格候选时调用 ComfyUI/Wan 生成 3–5 秒场景镜头；保存提示词、种子、模型、耗时与显存峰值。

**F3.5** 素材匹配不确定、生成失败或存在版权/事实风险时，输出待人工处理清单，不得静默替换为不相关画面。

**验收**：Day9 至少完成 3 个 Wan 情绪镜头实验；其余镜头可通过复用素材或模板提供初稿；每个镜头可追溯来源。

### P4｜初稿合成与人工审核

**F4.1** 按真实配音时间生成字幕和时间线，FFmpeg 合成 1080×1920 / 30fps MP4。

**F4.2** 导出独立素材、旁白、字幕和分镜清单；支持仅替换一个镜头后重新合成。

**F4.3** 保留人工审核，标注错读、错配、字幕错字、节奏问题与不合格镜头。

**验收**：生成完整 Day9 初稿；字幕与音频对齐；可在剪映继续精修；记录人工修改耗时。

## 6. MVP 成功标准

首要成功标准不是“所有功能完成”，而是**Day9 真正可以发布**。

- 声音：本人主观确认音色与自然度可发布。
- 画面：镜头与旁白语义匹配，无虚构产品演示；素材来源可追溯。
- 初稿：自动生成 9:16 MP4、SRT、独立素材与审查清单。
- 效率：以单条 60–90 秒视频为基准，记录脚本确认后至可发布的**人工操作耗时**；初步目标 ≤30 分钟，先测量基线，再判断是否达成。
- 复用：Day10、Day11 作为第二轮回归样本，检验是否减少重复生成。

**不把原 PRD 的“15 分钟全自动出片”直接作为首版承诺**。GPU 生成时长与人工验收时长分别统计。

## 7. 明确暂缓的原 PRD 功能

- 自动生成选题和带货脚本、Hook 库进化
- 数字人对口型与人物底板视频
- 夜间 10–20 条批量任务
- 粤语/普通话双语自动批量生产
- 多客户配置、权限、计费
- 自动发布、平台指标回流和复杂审核后台

以上功能不删除原有代码；本轮仅从新 MVP 的关键路径中移除。

## 8. 开发顺序与停点

1. **审计**：先对账本地 8 个提交、代码与模型环境；不得直接重构。
2. **配音实验**：Day9 本人音色完成可发布的旁白。
3. **Wan 实验**：三个真实分镜场景，测画质、显存、耗时。
4. **Excel + 导演**：完整镜头计划，优先复用素材与模板。
5. **初稿合成**：Day9 成片；统计人工修改时间。
6. **复用验证**：Day10 / Day11，之后再决定是否投入批量化。

任何阶段若发现关键质量或资源阻断，先报告替代方案和成本，等待持有人裁决；不得自行扩大项目范围。
