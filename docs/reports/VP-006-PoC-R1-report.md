## 三种效果分开配置

通用逻辑位于 [visual-effects.ts](../../experiments/day9-remotion/src/visual-effects.ts)，没有 Day9 文字或业务内容。配置位于 [effects-config.json](../../orchestrator/output/day9-vp006-poc-r1/effects-config.json)。复用既有 Remotion Sequence、Freeze 与 CSS 变换，不安装新转场依赖。

| 类别 | 实际调整 | 时间与帧数 | 语义依据 |
|---|---|---|---|
| 镜头入场 | zoom_in：开场轻缩放收定 | 0.000 秒开始，12 帧（0–11） | 让夜间工作场景自然建立，不以黑场开头 |
| 镜头间过渡 | crossfade：AI 场景进入摘镜实景 | 3.367 秒开始，12 帧（101–112），中心边界 107 | 从独自工作环境转到“熬夜、久坐、硬扛”的实际动作 |
| 镜头间过渡 | blur_transition：实景进入方法图解 | 8.567 秒开始，12 帧（257–268），最大 9 px 模糊 | “正确的做法”处由身体负担切换到清晰方法示意 |
| 镜头内部运动 | AI 静帧缓推并轻微平移 | 0–106 帧；比例 1.015→1.065，平移终点 -8/-5 px | 让静帧保持轻微空间变化，不改变语义 |
| 镜头内部运动 | 实景轻微推近 | 107–262 帧；比例 1.000→1.025 | 轻推近摘镜动作，保留原视频动作与源时间 |

通用最小集合包含 `hard_cut / crossfade / slide_in / blur_transition / zoom_in`，5 种均有逻辑及测试覆盖。`slide_in` 本片没有启用；图解已有模块进入动画，因此不再叠加整镜飞入。方法图解自身的充盈、拓宽和进度累加动画沿用原版。

字幕与品牌层位于画面效果层之外，不参与模糊、平移或缩放。字幕文字、短句时间、字体、屏幕位置和旁白时间原点均沿用原组件。
