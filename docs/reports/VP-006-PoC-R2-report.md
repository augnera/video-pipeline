## 3. 开场静态停留优化

真实原时间线首镜为 0–107 帧，主镜头 **3.5667 秒**。加上 R1 交叉淡化中原图仍可见的末尾 6 帧，单张图连续可见约 **3.7667 秒**，因此记录超过约 3 秒的提醒；提醒不是自动失败。

现有索引中 `mixkit-39839` 已下载并分析过。本次重新查看其 0、0.75、1.5 秒代表帧，确认人物在电脑前实际操作，手部位置发生变化。它此前因“疲劳动作不明显”而不用于疲惫表达，这个判断保持；本次目标是开场的办公动作细节，与当前旁白“把身体当成可以透支的资源”相符。

| 区间（主镜头） | R1 | R2 |
|---|---|---|
| 0–2.000 秒（0–60 帧） | 同一 AI 夜间工位静帧 | 保留该首帧，轻推移建立环境；这是静态图程序化运动，不是真实人物视频 |
| 2.000–3.567 秒（60–107 帧） | 仍为同一静帧 | 复用现有 `mixkit-39839` 原片 0–1.5667 秒，切入真实办公近景 |
| 3.567–8.767 秒（107–263 帧） | 摘镜实景 | 保持同一素材和原源时间 2–7.2 秒 |
| 8.767–18.200 秒（263–546 帧） | 方法图解 | 同一动画时序，改为居中构图并清理角标 |

在“身体透支”的语义段中由工作环境进入手与电脑的动作，再进入“熬夜、久坐、硬扛”的摘镜动作。只有一次开场短切镜，没有机械按固定间隔重复切换。

新增办公近景使用已存在的官方 Mixkit 文件，不新增下载。采用 952×1130 的内容窗口，保留手部、人物与部分显示器；原片 1920×1080，实际约 1.046 倍轻微放大，避免整屏竖裁造成过窄裁切与明显放大。没有额外标签。

原 `asset-catalog.json`、`asset-matches.json` 和 Asset Agent 契约保持不动；新增用途单独写在 [opening-asset-match.json](../../orchestrator/output/day9-vp006-poc-r2/opening-asset-match.json)，已经通过现有契约校验，人工状态仍待本轮审核。

## 4. 独立内容披露机制

装饰角标与内容披露分开处理，删除品牌及“情境示意”不代表豁免披露。

[content-disclosures.json](../../orchestrator/output/day9-vp006-poc-r2/content-disclosures.json)针对 AI 首帧记录 pending_review，尚未代替具体发布平台作出披露要求判断。当前为私人预览，不自动生成臆定的披露文字。

`content-disclosure.tsx` 支持独立的 pending_review / not_required / required：required 必须有明确文字，并在字幕上方独立显示，装饰角标关闭不影响该标记；pending_review 会使发布就绪检查返回 false。测试覆盖关闭装饰角标后 required 仍有效，以及缺文字/未知状态拒绝通过。该机制不是公共发布服务，也不意味着当前素材已获公开发布许可。
